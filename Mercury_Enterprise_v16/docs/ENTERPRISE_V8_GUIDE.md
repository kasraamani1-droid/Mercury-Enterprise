# Mercury Enterprise v8.0 Guide

## Workspaces
- Command: live simulated incident operations
- Digital Twin: airport asset and target visualization
- Radar: rotating scope and contacts
- Executive: management KPIs
- History: searchable archive and CSV export
- Admin: roles, presence, integrations, audit log
- Cloud: topology, capacity, and recovery readiness
- Integrations: connector catalog and developer access
- Compliance: simulated governance and control coverage

## Validation
Run `CHECK_SYSTEM.bat`, then `START_ALL.bat`. Backend tests can be run from `backend` with `py -m pytest -q`.

No certification or operational suitability is claimed.
