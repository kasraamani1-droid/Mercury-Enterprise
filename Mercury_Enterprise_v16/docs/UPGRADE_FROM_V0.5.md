# Upgrade from v0.5

This version is a complete replacement package. Do not copy individual files into v0.5.

1. Keep your v0.5 folder as a backup.
2. Extract v0.6 into a new folder.
3. Start v0.6 using `START_ALL.bat` or the two individual startup files.
4. The included SQLite database contains the demonstration incidents from the packaged build.
