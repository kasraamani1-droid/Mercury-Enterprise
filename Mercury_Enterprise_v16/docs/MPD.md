# Maintenance Planning Document (MPD)

MPD tasks bind to a **program revision** and drive check/job-card generation.

## Fields

Task Number · Title · ATA · Description · Skill · Manhours · Interval (calendar / FH / FC / landings / engine / APU / component) · Threshold · Repeat · Publications · Tools · Parts · Certifications · Inspection / II / ACA flags · Applicability · Status · Revision label

## APIs

`GET/POST /api/v1/planning/mpd-tasks`
