# Marketplace — Future Roadmap

1. **Payment gateway** via Mercury Connect binding (vault secrets, no plaintext).
2. **Shipping carriers** — track numbers, label APIs, courier connectors.
3. **Document verification pipeline** — OCR/hash of 8130 / Form 1 uploads (still not regulatory attestation).
4. **Fraud detection** — velocity rules, anomalous pricing, duplicate seller graphs.
5. **Cross-tenant public catalog** — opt-in seller visibility beyond owning org (requires marketplace directory tenancy model).
6. **AI advisory** — recommendations, supplier ranking, alternate parts, repair suggestions, training/career matching (advisory-only per ADR-0008).
7. **Vanilla JS marketplace UI** — browse, cart, quote, order tracking inside existing shell.
8. **Inventory sync** — logistics stock ledger ↔ marketplace qty_available.
9. **Multi-line RFQ** — quote headers with many lines / competitive bidding.
10. **Military buyer** segment when classification controls mature.
